hwptopdf 1.1 — 한글 문서 PDF 일괄 변환
==================================================

■ 쓰는 법 — 바탕화면의 "hwptopdf" 를 실행하세요
   (또는 프로그램 폴더의 hwptopdf.exe)

  검은 명령창(터미널)은 뜨지 않습니다. 앱 창 하나만 뜹니다.

  폴더를 지정하는 방법 (아무거나)
    · 앱 창에 폴더를 끌어다 놓기
    · 바탕화면 아이콘 위에 폴더를 끌어다 놓기
    · 경로 칸에 붙여넣기 (Ctrl+V) → Enter   ← 공유폴더는 이게 편합니다
    · [찾아보기...] 버튼
  → 클립보드에 폴더 경로가 있으면 자동으로 채워집니다.
  → Explorer에서 "경로로 복사"한 따옴표(" ")는 자동으로 처리됩니다.

  진행 순서
    1. 폴더 지정 → [파일 찾기]     : 변환할 파일 목록이 표시됩니다
    2. [변환 시작]                 : 파일별로 상태가 실시간으로 바뀝니다
                                     (대기 → 변환 중 → 완료/건너뜀/확인필요/실패)
    3. 끝나도 창은 닫히지 않습니다  : 아래에 최종 리포트가 나옵니다
    4. [결과 폴더 열기] / [기록 열기] 로 바로 확인

  · 오래 걸릴 때는 [중단]을 누르면 현재 파일까지만 끝내고 멈춥니다.
  · 변환 중에는 창이 닫히지 않습니다(실수 방지).


■ 결과가 어디에 생기나

  HWP가 있는 각 폴더 안에  [그 폴더 이름]_변환PDF  폴더를 만들어 넣습니다.

    2026년 회의\
      ├ 1월 회의.hwp
      ├ 2026년 회의_변환PDF\
      │    ├ 1월 회의.pdf
      │    └ 변환로그_20260822_114016.txt
      └ 회의결과\
           ├ 5월.hwp
           └ 회의결과_변환PDF\
                └ 5월.pdf

  왜 이렇게 하나:
    상위 폴더를 지정하든 하위 폴더를 지정하든 결과가 늘 같은 자리에 생깁니다.
    그래서 나중에 하위 폴더만 따로 변환해도 같은 PDF가 두 군데 생기지 않습니다.
    (이미 만들어진 PDF는 건너뛰므로 그냥 넘어갑니다)

  · _변환PDF 폴더 안은 다시 훑지 않습니다. 몇 번을 돌려도 안전합니다.
  · 기록 파일은 지정한 폴더의 _변환PDF 안에 남습니다.

  ▶ 원본과 같은 폴더에 만들고 싶으면
    앱에서 "PDF를 원본과 같은 폴더에 만들기 (하위 폴더 없이)" 를 켜세요.
    이 선택은 기억되어 다음에 열 때도 유지됩니다.

      2026년 회의\
        ├ 1월 회의.hwp
        ├ 1월 회의.pdf          ← 원본 옆에 바로
        └ 회의결과\
             ├ 5월.hwp
             └ 5월.pdf

    명령줄에서는 -SameFolder 옵션입니다.


■ 안전장치

  · 원본 HWP는 열고 닫기만 합니다. 수정도 삭제도 하지 않습니다.
  · 같은 이름의 PDF가 이미 있으면 건너뜁니다.
    → 여러 번 돌려도 안전합니다. 중간에 끊겨도 이어서 하면 됩니다.
  · 변환할 때마다 원본 HWP의 페이지 수와 만들어진 PDF의 페이지 수를
    대조합니다. 다르면 "확인필요"로 표시하고 넘어갑니다.
  · 무엇을 했는지 변환로그 파일로 남깁니다.


■ 모아찍기는 자동으로 바로잡습니다

  문서에 "모아 찍기"가 켜져 있으면 한 장에 2쪽·4쪽씩 들어가서, 8쪽짜리가
  4쪽 PDF로 나옵니다. 내용이 빠진 건 아니지만 보기에 불편합니다.

  이 프로그램은 변환 뒤 쪽수가 안 맞으면 PDF 프린터로 한 번 더 뽑아
  한 장에 한 쪽씩 나오게 바로잡습니다. 사용자가 할 일은 없습니다.

  쓸 수 있는 PDF 프린터가 없으면 바로잡지 못하고 "확인필요"로 남습니다.
  그때는 다음 중 하나를 설치하세요.

    · Hancom PDF
      한컴오피스 설치 시 함께 제공됩니다. 설치할 때 빼셨다면 한컴오피스
      설치 관리자에서 다시 설치하거나, 한글 설치 폴더의
      HancomPDF\SetupDriver.exe 를 실행하세요.

    · Microsoft Print to PDF
      Windows 기본 기능입니다. [설정] → [Bluetooth 및 장치] →
      [프린터 및 스캐너] 에서 추가하거나, [Windows 기능 켜기/끄기] 에서
      켤 수 있습니다.

  둘 중 아무거나 하나만 있으면 됩니다.


■ "확인필요"가 나왔다면

  원본과 PDF의 쪽수가 다르고, 위의 자동 보정으로도 해결되지 않은 경우입니다.

  · "모아찍기 N쪽 추정" — 내용은 다 있습니다. PDF 프린터를 설치하면
    다음 변환부터 자동으로 한 쪽씩 나옵니다.
  · "일부만 저장됐을 수 있습니다" — 인쇄 범위가 문서 전체가 아닐 수
    있습니다. 한글에서 [파일]-[인쇄] 범위를 "문서 전체"로 바꾼 뒤
    "이미 만들어진 PDF도 다시 변환"을 켜고 다시 실행하세요.

  확인필요·실패 항목은 기록 파일에 전체 경로가 남으므로, 나중에
  어느 파일이었는지 바로 찾을 수 있습니다.


■ 명령줄로 쓰기 (자동화·배치용, 평소엔 쓸 일 없음)

  앱 없이 돌리고 싶을 때만 쓰세요.

    명령줄변환.bat "폴더경로"

  PowerShell에서 직접:

    convert.ps1 "폴더경로"                     기본
    convert.ps1 "폴더경로" -Force              이미 있는 PDF도 다시 만들기
    convert.ps1 "폴더경로" -OutDir "다른폴더"   PDF를 지정한 곳에 모으기
    convert.ps1 "폴더경로" -SameFolder         PDF를 원본과 같은 폴더에 만들기
    convert.ps1 "폴더경로" -NoVerify           페이지 수 대조 생략 (자동화 전용)

  ※ 앱에서는 페이지 수 대조를 항상 합니다(끌 수 없음). -NoVerify 는 대량
    자동화처럼 속도가 중요한 경우를 위한 명령줄 전용 옵션입니다.

  종료 코드: 0 정상 / 1 대상 없음 / 2 한글 없음 / 3 실패 있음


■ 요구사항

  · 한글(한컴오피스)이 설치되어 있어야 합니다.
    설치된 한글이 변환을 하므로 표·서식이 원본 그대로 나옵니다.
  · 변환 중에는 한글이 백그라운드로 파일을 여닫습니다.
    한글로 직접 작업 중이면 잠시 피하는 게 좋습니다.


■ 어디에 두어야 하나 — 아무 폴더나 괜찮습니다

  이 프로그램은 폴더 하나만 있으면 되고, 설치 과정이 없습니다.
  Program Files 아래에 두셔도 됩니다.

    C:\Program Files\hwptopdf\        여러 사용자가 함께 쓰는 PC에 적합
    %USERPROFILE%\Tools\hwptopdf\     혼자 쓰는 PC에 적합 (관리자 권한 불필요)

  Program Files 에 둘 때 알아둘 점
  · 폴더를 복사할 때만 관리자 권한이 필요합니다. 실행할 때는 필요 없습니다.
    (프로그램은 자기 폴더에 아무것도 쓰지 않습니다. PDF와 기록은 변환 대상
     폴더에 생깁니다)
  · 보안 승인 모듈은 사용자별 설정이라, PC를 함께 쓰는 사람마다 각자
    한 번씩 "설치.bat"을 실행해야 합니다. 이때도 관리자 권한은 필요 없습니다.
  · 나중에 스크립트를 수정하려면 관리자 권한이 필요합니다.

  ※ 폴더를 옮기면 바탕화면 바로가기가 끊어집니다. 옮긴 뒤 hwptopdf.exe 를
    마우스 오른쪽 → [보내기] → [바탕 화면에 바로 가기 만들기] 로 다시 만드세요.


■ 다른 PC에 옮길 때 — 설치.bat 을 한 번 실행하세요

  이 폴더를 통째로 복사한 뒤, 그 PC에서 "설치.bat"을 더블클릭하면 끝입니다.
  관리자 권한이 필요 없습니다. (HKCU와 사용자 폴더만 씁니다)

  설치.bat 이 하는 일:
    1. 한글 설치 여부 확인
    2. 한컴 공식 배포처에서 보안 승인 모듈을 내려받기
    3. 파일 지문(SHA256) 대조 — 다르면 설치를 중단합니다
    4. %USERPROFILE%\Tools\HancomAutomation\ 에 설치
    5. 레지스트리 등록 후, 실제로 로드되는지 검증

  되돌리기:  명령 프롬프트에서
             설치.bat -Uninstall


■ 한글 보안 승인 팝업에 대하여

  한글 자동화는 원래 파일에 접근할 때마다 보안 승인 팝업을 띄웁니다.
  위 설치.bat 이 등록하는 모듈이 그 팝업을 없앱니다.

    DLL      : %USERPROFILE%\Tools\HancomAutomation\FilePathCheckerModuleExample.dll
    출처     : https://developer.hancom.com/hwpautomation
               (한컴 공식 GitHub: github.com/hancom-io/devcenter-archive)
    SHA256   : 9AC5B97C47AC8AED1E8BCA27A3EEF39411361D8F68C262509F0C40A8F9D21BB6
    레지스트리 : HKCU\Software\HNC\HwpAutomation\Modules
                HKCU\Software\HNC\HwpCtrl\Modules
                값 이름 = FilePathCheckerModuleExample
                값 데이터 = 위 DLL 전체 경로 (따옴표 없이)

  이 모듈이 하는 일:
    한글이 "이 경로에 접근해도 되냐"고 물으면 무조건 "예"라고 답합니다.
    (한컴이 동봉한 C++ 소스를 확인한 결과 그것이 전부이며,
     네트워크 통신이나 파일 조작은 하지 않습니다.)

  달리 말하면 파일 접근 확인 절차를 끄는 것입니다. 자동화에는 필요하지만,
  출처가 불분명한 스크립트를 한글 자동화로 돌리지 않도록 주의하세요.

  ※ 한컴이 파일을 갱신하면 지문이 달라져 설치가 중단됩니다.
     그때는 정말 한컴이 바꾼 것인지 확인한 뒤 install.ps1 의
     $ExpectedSha256 값을 새 지문으로 고치세요.

■ 파일 구성

  hwptopdf.exe   앱 실행용 ★ (여기에 폴더를 끌어다 놓거나 더블클릭)
  hwptopdf.vbs   exe 없이 실행할 때 쓰는 예비 실행기 (동작은 같음)
  gui.ps1        앱 화면 코드
  core.ps1       변환 로직 (앱과 명령줄이 함께 씀)
  convert.ps1    명령줄판
  명령줄변환.bat   명령줄 실행용
  설치.bat        보안 승인 모듈 설치용 (새 PC에서 한 번만)
  install.ps1    설치 코드
  launcher.cs    hwptopdf.exe 소스
  build-exe.ps1  exe 빌드 스크립트 (Windows 내장 컴파일러만 사용)
  app.ico        앱 아이콘
  사용법.txt      이 파일
  LICENSE        PolyForm Noncommercial 1.0.0
  THIRD-PARTY-LICENSES.md   한글·한컴 보안 모듈 관련 고지

  ※ 앱 안의 [정보] 버튼을 누르면 버전·제작자·라이선스와 함께
    사용법·라이선스·고지 문서를 바로 열 수 있습니다.

  ※ .ps1 파일은 반드시 UTF-8(BOM 포함)으로 저장할 것.
    BOM이 없으면 Windows PowerShell 5.1이 한글을 깨뜨립니다.
  ※ .bat / .vbs 파일의 내용은 ASCII만 쓸 것.
    cmd.exe는 OEM 코드페이지로 읽습니다. (파일 이름이 한글인 건 괜찮습니다)
  ※ .bat / .vbs 는 줄바꿈을 반드시 CRLF로 저장할 것.
    LF(유닉스 방식)로 저장하면 cmd.exe가 파일 위치를 잘못 추적해서,
    pause 이후 배치가 다시 실행되는 증상이 납니다. 실제로 겪은 문제입니다.
  ※ 코드를 고칠 때 주의할 점 두 가지 (실제로 겪은 문제)
     · 제네릭 List에 @() 를 씌우면 이 환경의 PowerShell 5.1이
       "Argument types do not match" 예외를 냅니다. .ToArray() 를 쓰세요.
     · 드래그앤드롭으로 받는 매개변수에는 Position = 0 을 반드시 주세요.
       빼면 경로가 뒤의 문자열 매개변수로 잘못 들어갑니다.
